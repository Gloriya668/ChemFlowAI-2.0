# 知识库与数据集 V2（2026-10-10）

本版新增 16 份有依据的中文工程检查清单和 3 份固定版本 IDAES 文档的分块。知识库现有 **79 条资料、37 个来源组**，保留 21 个 DWSIM 原始流程案例。原始文件、SHA256、许可及中文清单引用链都在 `knowledge_base/source_manifest.json`。

新增官方来源包括 IDAES 的模型诊断、通用工作流和初始化文档，使用固定提交 `5e51567b315a25a4ed0057b4a23afe02f1109482`，遵循随附 BSD-3-Clause 许可。知识库补充诊断步骤，不意味着本应用已安装或调用 IDAES 求解器。

- 通用工作流：https://idaes-pse.readthedocs.io/en/stable/how_to_guides/workflow/general.html
- 固定来源：https://github.com/IDAES/idaes-pse/tree/5e51567b315a25a4ed0057b4a23afe02f1109482/docs

训练数据统一入口见 `training/README.md`。SFT 训练集 116 条、开发集 22 条、测试集 38 条；包含基于证据作答和 Agent 下一步动作两类。Agent 48 条情境覆盖授权、阶段、缺失模板、重复求解、版本变化、注入文本、参考回放、缺少能量证据等；它们是合成样本，不是实际工具执行轨迹。

本版特别修正了来源划分：同一文件的分块和引用它的中文清单不能跨训练与测试集。所有合成样本显式标识；每条知识资料提供专家审核占位字段。自动审核报告在 `training/audit_report.json`。

已随数据重训本地轻量排序器。22 条内部检索测试中：BM25 首条命中 18/22，训练排序器 19/22，双方前三命中 21/22；MRR 分别为 0.8874 与 0.9101。只多命中一条，样本量小且包含历史回归查询，不能据此推断广泛泛化提升。逐条排名和失败项保留在 `training/evaluation.json`。

大模型微调、真实大模型动作评测仍为未执行。12 项工程级验收计划也明确标为 `NOT_RUN`，需要可信仿真环境、真实模板、独立参考值和预登记容差后执行。API Key、base_url、model 保持空白。

使用方法不变：安装后启动应用，在项目“工程 Agent 任务”展开工程知识库即可检索；Agent 已自动使用更新语料和排序权重，无需另行接线。此前 `知识库与训练说明.md`、`知识库训练验收.md` 是 v1 历史记录，当前以本说明和本版审计/评测 JSON 为准。
