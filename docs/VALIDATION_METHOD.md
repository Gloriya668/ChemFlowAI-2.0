# 验证方法
工作流集成验证与独立数值验证分开报告。回放可验证读取、字段映射、单位、拓扑、交互、状态机和导出，不证明真实求解器收敛或物理模型准确。Independent Numerical Validation 始终 NOT_ASSESSED。

Step09 比较流股集合、T/P/质量流量、设备及连接、能量条目和前序审批。阈值在 config/validation_thresholds.json：温度0.05°C，压力0.005bar，流量相对0.0001，外部质量衡算相对0.001，能量相对0.0001。阈值可配置，不代表行业认证标准。源数据异常不因与同源标答匹配而消失。

测试覆盖四条完整后端路线、越步阻断、输入修改使下游失效、盲验证断路、单位换算、工程数值来源、技能契约和非法连接。浏览器覆盖两体系九步、来源弹窗、SVG 设备/流股点击、刷新恢复、导出及零远端网络请求。
