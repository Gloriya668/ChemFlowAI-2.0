# 大模型配置

编辑 `config/llm.json`，填写三个空字符串：

```json
{
  "api_key": "",
  "base_url": "",
  "model": "",
  "timeout_seconds": 90
}
```

- api_key：模型供应商的 API 密钥。
- base_url：供应商提供的 API 基础地址（通常包含 `/v1`）；程序在其后添加 `/chat/completions`。也接受完整的 `/chat/completions` 地址。不要填写网页聊天地址。
- model：供应商提供的准确模型 ID。
- 接口需兼容 Chat Completions，支持 messages、非流式文本响应和 Bearer API Key。

也可通过环境变量 `CHEMFLOW_LLM_API_KEY`、`CHEMFLOW_LLM_BASE_URL`、`CHEMFLOW_LLM_MODEL` 覆盖配置。配置文件修改下次请求即生效；环境变量修改需要重启服务。密钥不会返回前端，不应将填写过的配置分享给别人。

按原有方式运行 `Setup-Offline.ps1`（首次安装）及 `Start-ChemFlow.cmd`。打开项目，在每个阶段下方的“大模型工程助手”点击“测试连接”，然后提问或点击“分析当前阶段”。配置状态与真实连接测试分开显示。在线模型需要网络，原有规则解析与工程计算在未配置模型时仍可使用。

问答会发送当前阶段已保存的设计基准、可见工程结果及最近六轮对话。草稿需要先保存；对话仅保留在当前页面，切换阶段或刷新会清空。输出仅供审阅，不自动修改参数、调用求解器或替代人工批准。

接口：`GET /api/llm/status`、`POST /api/llm/test`、`POST /api/projects/{pid}/ai/chat`。最后一个接口的请求体为 `{"message":"问题","history":[],"step":1}`。

配置缺失、认证错误、限流、网络异常、超时和响应格式错误均显示明确提示，不使用演示回复冒充模型结果。HTTP 超时实现参考 [HTTPX 文档](https://www.python-httpx.org/advanced/timeouts/)。
