# ChemFlow AI 交付报告（16项）
1. **目录**：backend 为 FastAPI 状态机/适配器/Evaluator；frontend 为 React+TypeScript+Vite+Tailwind；data 为输入、回放、标答和 SVG；config 为阈值/Schema；skills 为六个正式技能；docs、tests、offline_wheels 与启停脚本齐备。
2. **启动**：本机双击 Start-ChemFlow.cmd，打开 http://127.0.0.1:8765。新机器先用 Setup-Offline.ps1 指定 Python3.12 x64 路径；无需运行 npm 即可启动本地工作台。
3. **页面**：首页、任务列表、新建任务、九个步骤、报告路径，至少13个路由界面。深色工作台包含导航、步骤条、工程画布、Inspector 和底部动作。
4. **状态机**：九步顺序解锁，人工复核、模型/路线/回放等前置条件由后端强制执行；持久化 JSON；上游修改明确确认后清除下游结果。
5. **技能结构**：六个 SKILL.md 均带 references/contract.md，通过正式格式检查，执行结果使用统一 SkillResult。
6. **技能用途**：intake 接收输入；property-modeling 物性缺口与模型候选；process-synthesis 拓扑筛选；simulation-review 来源和衡算；optimization-tea 变量与经济缺口；validation 最终评估。检索仅访问当前技能本地参考文档。
7. **标答隔离**：运行时标答只由最终 Evaluator 读取；前四步只持有输入和拓扑，网页静态根不包含数据目录。
8. **回放来源**：两个用户 Excel，四套路线51条流股，记录单元格及来源链；fixture 与标答同源，独立数值验证 NOT_ASSESSED。
9. **桩接口**：DWSIM/Aspen MCP 明确未连接；Blind 在 Step05 阻断，无假收敛或任意 COM 路径执行。
10. **可视化**：复用四套既有 SVG 拓扑与动画，真实绑定流股值；支持突出字体、流股/设备选择、来源检查、悬停、缩放平移、暂停及减少动态偏好。
11. **测试**：32项后端测试、六技能格式校验、两体系完整九步浏览器测试及离线安装检查；详见 TEST_REPORT.md。前端生产构建通过。
12. **限制**：没有独立求解器、真实优化和实验物性验证；异常存档保留；不完整经济条件不生成投资回报指标；仅本机单用户。
13. **DWSIM 接入**：实现 IR 映射、超时和日志、真实收敛与单位校验，再开展独立标答比较。
14. **Aspen 接入**：对接授权 Aspen/MCP、类型白名单和会话管理，保存真实模拟输出和来源。
15. **下一步**：先修复/核查吡啶源数据异常和模型警告，再补物性/BIP与成本依据，接入一个真实求解器，最后做约束优化和完整 TEA。
16. **工程工作流路径**：首页→创建工程任务→逐步复核设计和物性→选模型→选路线→加载参考回放→点选流股看来源→确认能量审查→保存参考基线→复核经济数据缺口→最终评估→下载报告与成果包。Blind 任务在 Step05 显示未连接状态，上游修改会使下游结果失效。
