# 财务计算口径与核对记录

本模块按独立项目计算，用户已明确丙烷/丙烯需另补价格与投资。财务试算不写入工艺项目、不解锁阶段，也不继承其他项目投资额。年度收支草稿按项目ID及情景ID保存在浏览器。

## 资料归属

- `4. 本项目财务分析(1).xlsx`：对应经济分析报告中的异丙醇/异丙醚联产项目，采用“财务现金流量”C:Q列的逐年收入、残值、资金回收及六项支出，单元格缓存值与公式一并提取核对。折现率12%。
- `4. 本项目财务分析.xlsx`：独立1.8万吨异丙醇情景。经营成本引用产品成本汇总C15空白，不能当零；建设投资按一半金额连续计三年，需核实分配。
- `吡啶回收期计算.xlsx`：独立吡啶情景，现金流表第3行为年份。采用逐年收支，不采纳漏掉第三年支出的累计公式。40%为给定折现率情景，不是推荐基准。
- `1. 本项目投资费用计算.xlsx`：投资48676.2011万元，与联产项目23340.1759万元不同，未跨项目替换。
- `2. 本项目产品成本计算.xlsx`：总成本13669.6909万元，可变成本11000万元，经营成本行11240万元又扣除了维修费，不能直接替换完整经营成本，保留待核实。
- `3. 本项目收入计算.xlsx`：1.8万吨异丙醇、15000元/吨、收入27000万元。与吡啶现金流30000万元不同，分开处理。
- `吡啶项目财务分析.xlsx`：三张空工作表，没有可提取的财务数值。
- `结果.xlsx`：吡啶物流结果，没有完整投资、价格及年度现金流，未从物流臆造财务结果。
- `泵计算.docx`：工艺流量2.14m³/h与选型流量25m³/h存在明显差别，轴功率2.13kW没有运行负荷、电价及计费边界，不另加到现有经营成本，避免重复计费。
- `6-经济分析报告-改1.docx`：项目与联产情景匹配，但正文及表格个别折现、残值及数字存在冲突。用于核对边界，不覆盖逐年收支。
- `可行性报告.doc`：封面乙二腈、概述己二腈、目录及部分正文异丙醇混用，多项财务结论留空。只读提取，未用于跨项目补数。

## 算法

金额统一万元，现金流发生于年末，第1年为建设开始后的第一年。CF逐项相加减；NPV为逐年CF折现之和。静态与动态回收期分别用累计CF与累计折现CF首次跨零的年度内插值，包含建设期。未跨零显示期内未回收，不输出0。缺少收支金额则不计算。IRR求NPV零点，对多次变号、无根现金流不报告单一结果。

参考公式定义：https://support.microsoft.com/en-us/excel/functions/npv-function 及 https://support.microsoft.com/en-us/excel/functions/irr-function 。不引用原表对累计现金流再次折现的错误公式。

由于现金流含偿还本息、缺乏完整融资流入，指标标为“收支口径IRR”，不是全投资IRR或股权IRR。税金沿用年度金额输入，未将历史税率宣称为当前适用法规。投资安排、税费及费用分类冲突仍列为待确认。

## 验证

单元测试验证年度折现、回收期插值、空值、非有限输入、年度连续性、情景隔离和负转正条件。浏览器验证计算、调整折现率后清除旧结果、缺少经营成本时拦截、PNG和CSV导出。前后比对项目对象，无流程及阶段状态变化。
