# 数据与来源隔离
原始来源为桌面《丙烯丙烷数据最最最最终版.xls》和《四氢糠醇_所有流股结果.xlsx》，四套拓扑复用已审核的 Aspen 流程可视化。每个可用流股值记录文件、工作表/单元格、版本及状态；预处理清单保存源文件摘要。

输入设计基准只包含外部进料和定义。回放 fixture 位于 data/replay；标答位于 data/validation 下的 ground_truth.json。两者来自同一 Aspen 存档，因此不是独立数值验证。运行时只有 Step09 Evaluator 读取标答。前端静态服务不暴露 data/backend/config/runtime；本机文件并非加密保险箱。

51 条流股覆盖普通精馏8、热泵18、内部热耦合12、吡啶13。未知组成和相态不推断。压力保留原表 bar，不擅自定义表压或绝压。cal/sec 转 kW 乘0.004184；普通再沸器61.9943162976 Gcal/day 按 ×4184000÷86400 转 kW，保留原值和计算父项。内部热耦合压缩机功率349.053702 kW 已纳入。

吡啶 A-S2、A-S3 的异常低温、PY-R/B2 警告原样保留。吡啶采用最新六设备开环图，不将早期截图中缺数据的分相循环补造到当前模型。
