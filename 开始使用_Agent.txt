ChemFlowAI Agent + DWSIM 接入版

1. API Key、base_url、model 都留在 config/llm.json，空着等你填写。
2. 按原方法运行 Setup-Offline.ps1 和 Start-ChemFlow.cmd。
3. DWSIM 使用官方运行 ZIP：dwsim-10.2.11-win-x64.zip。执行：
   .\Setup-DWSIM.ps1 -RuntimeZip "C:\你的路径\dwsim-10.2.11-win-x64.zip"
   你提供的 dwsim-windows.zip 是源码，不是运行包。
4. 打开项目，使用“工程 Agent 任务”，可检查需求、检索依据、查看工具轨迹。
5. 真实求解需要登记你自己的 DWSIM 模型、标签和输入指纹。说明见 docs/Agent与DWSIM接入说明.md。
